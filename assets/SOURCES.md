# Image sources

## ภาพวัตถุดิบสายปั่นที่ผู้ใช้ให้มา

ไฟล์ `assets/raw/chaos/*.png` มาจากภาพที่ผู้ใช้แนบมาในบทสนทนา และถูกตัดพื้นหลัง/ปรับขนาดเพื่อใช้เป็นวัตถุดิบภายในเกมงานนี้

These images are used for an educational student project and stored locally so the application does not depend on an external image API.

- Deconstructed burger layers: CityPNG, “HD Fast Food Burger Cheeseburger Layers PNG”  
  https://www.citypng.com/photo/23016/hd-fast-food-burger-cheeseburger-layers-png
- Beef patty: PNGWing, “Hamburger Patty Breakfast Sausage Bread”  
  https://www.pngwing.com/en/free-png-dogil
- Pork patty: Rawpixel, “Grilled Pork Burger Patty”  
  https://www.rawpixel.com/search/pork%20patties
- Crispy chicken patty: Perkchops ingredient image  
  https://perkchops.com/ingredients/crispy-chicken-patty
- Fried squid rings: TOPpng, “Battered Squid Rings”  
  https://toppng.com/free-image/so%C4%9Fan-halqalar%C4%B1-battered-squid-rings-PNG-free-PNG-Images_243032

Check each source’s current license and attribution terms before any commercial use.
